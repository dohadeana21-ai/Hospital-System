# 🏥 Hospital Management System

A simple **Hospital Management System** built using **C++** and **Object-Oriented Programming (OOP)**.

This project allows users to manage patients and doctors, assign doctors to patients, and search for records through a menu-driven console application.

---

## ✨ Features

### 👨‍⚕️ Doctor Management
- Add new doctors.
- Prevent duplicate doctor names.
- Search for doctors by name or specialty.
- Display all registered doctors.

### 🧑‍🤝‍🧑 Patient Management
- Add new patients.
- Prevent duplicate patient names and phone numbers.
- Search for patients by name or phone number.
- Display all registered patients.

### 🔗 Doctor Assignment
- Assign doctors to patients.
- Prevent assigning the same doctor to a patient more than once.
- Display the doctors assigned to each patient.
- Display the patients assigned to each doctor.

---

## 🛠️ Technologies Used

- C++
- Object-Oriented Programming (OOP)
- Classes & Objects
- Constructors
- Encapsulation
- Vectors
- Functions
- Loops & Conditions
- Windows API (`windows.h`) for console text colors

---

## 📋 Main Menu

The program provides three main options:

1. **Patient Management**
2. **Doctor Management**
3. **Exit**

Each section has its own submenu to manage records.

---

## 🔍 Search System

The project supports searching using:

- Patient name or phone number.
- Doctor name or specialty.

Name searches are case-insensitive and support searching by full name or first name.

---

## 🚀 How to Run

1. Download or clone the repository.
2. Open the project in a C++ IDE such as Code::Blocks.
3. Make sure your compiler supports `windows.h`.
4. Compile and run the program.

---

## 📝 Notes

- Patient and doctor records are stored using `vector`.
- Data is stored temporarily in memory and will be lost when the program closes.
- The project currently uses a console-based interface.
